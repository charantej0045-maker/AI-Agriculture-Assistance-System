# AI Agriculture Assistance System

This is a simple beginner-friendly full-stack project for an AI agriculture dashboard.

## Features
- Farmer login page
- Dashboard for farm input values
- AI-style crop recommendation
- Fertilizer suggestion
- Yield and water prediction
- Download report as CSV file

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask

## Run the project
1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
2. Start the server:
   ```bash
   python app.py
   ```
3. Open in browser:
   ```text
   http://127.0.0.1:5000/
   ```
